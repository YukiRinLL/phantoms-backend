## 三、配置使用示例

### 3.1 房屋监控配置

在数据库 `config.system_config` 表中配置 `housing.sale.notify.targets` 字段：

```json
[
  {
    "server": "1121",
    "areas": "0,1,2,3,4",
    "group-ids": "787909466"
  }
]
```

- `server`: 服务器ID，对应上方服务器列表
- `areas`: 住宅区ID列表，多个用逗号分隔，对应上方住宅区列表
- `group-ids`: 接收通知的QQ群ID，多个用逗号分隔

### 3.2 代码引用

服务器ID映射定义在：
- `HousingSaleScheduler.java` 中的 `SERVER_NAME_MAP` 常量

住宅区ID在以下位置使用：
- `HousingSaleScheduler.java` 的房屋监控逻辑
- 数据库配置 `housing.sale.notify.targets` 的 `areas` 字段
